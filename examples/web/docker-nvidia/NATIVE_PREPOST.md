# 原生预处理、段落后处理与双实例并发（2026-10-29）

部署镜像：`wxocr-web:cuda-native-20261029`。GPU 1 为 RTX 4090，服务地址 `http://10.100.5.250:7676/`。

## 当前配置

`engine_workers: 2`、`max_concurrent_tasks: 2`、`model_resident: true`、`startup_warmup: true`。两个独立引擎各自加载并预热，监听前全部完成；单个引擎内部仍串行。繁忙时返回 429，不提供请求队列。

**全服务限速仍为每分钟 60 次**，使用令牌桶，启动时可突发 60 次。压测使用隔离容器、关闭该限速；下述吞吐是处理能力，不代表线上持续允许的请求速率。

## 热请求耗时（毫秒）

同机同图，旧/新版本顺序执行；每图先预热一次，再测 7 次，取算术平均。包含图片解码和完整 OCR，不含 HTTP、JSON 与预览编码。其他宿主业务保持运行。

预处理使用 C 原生定点双线性缩放与行缓存，系数及归一化查表由 Go 生成，保持原来的舍入；NRGBA、RGBA、Gray 直接读取像素，其他格式走原 Go 路径。段落开运算改为四次可分离扫描；多边形概率统计改为扫描线覆盖，保留边界点及原逐行求和顺序。模型权重与精度未改变。

## HTTP 并发压测

每组 60 次请求，中文、票据、双栏各 20 次，省略预览；临时容器任务上限为 2、限速为 0。P50/P95 为客户端完整耗时。两实例的吞吐相对同版单实例、两客户端提高约 1.89 倍。

`before` 为原紧凑 CTC 镜像；`native1/native2` 为本次相同镜像不同实例数。短测受同机负载影响，未做长期容量承诺。两个实例创建至就绪约 6–7 秒。
