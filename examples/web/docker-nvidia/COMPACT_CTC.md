## 实现与等价性

原识别输出为 `[1,T,13564]`，每行整张概率矩阵都回传到 CPU，随后扫描全部类别。
现在使用 GPU `Softmax → TopK(k=1) → Gather → Concat`，输出 `[1,T,T+2]`：

- 每一行的第 0 项为该时间步的贪心字符 ID，第 1 项为 blank 概率。
- 后续 T 项为“每个时间步候选字符”在当前时间步的概率，重复字符保留身份映射。
- Top-1 只复现原有贪心决策；CTC 置信度仍使用目标序列所有字符在所有时间步的概率及 blank，保留原来的完整路径求和，不做概率重归一化或 Top-K 近似剪枝。
- 字符 ID 最大 13563，转换为 float32 不损失整数精度；并列最大值仍选择最小字符索引。

算子记录确认 TopK、Softmax 和概率筛选在 CUDA 上执行。早期 ArgMax 方案因回落 CPU 而未发布。
以 T=128 为例，输出由 6,944,768 字节降至 66,560 字节，减少约 104 倍。
原始模型、权重及精度设置保持原有状态；CUDA 镜像构建时生成派生模型。
核心兼容原 logits、完整 probabilities 和新 `ctc_compact_v1` 三种输出。

新增 `Engine.Warmup(ctx)`：检测长边 960、短边 160–960 的所有档位，7 个文字行宽度档位（64–960），以及段落固定尺寸，均运行两轮。
Web 配置 `startup_warmup` 默认 false，NVIDIA 配置为 true；要求 `model_resident: true`，失败时退出且不开放监听。
