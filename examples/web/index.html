通过 API 调用
POST ./api/ocr · 请求头 Authorization: Bearer YOUR_TOKEN · 使用 multipart/form-data 上传图片。响应为 application/json。


接口文档
请求字段：image（必填，JPEG / PNG 文件）。查询参数：preview（可选，true / false，默认 false）；为 true 时返回 PNG Base64 预览。完整请求最大 20 MiB，图片最多 2500 万像素。浏览器使用 FormData 时请让浏览器自动生成 Content-Type 和 boundary。


成功响应（HTTP 200）：
{
  "result": {
    "width": 1000,
    "height": 600,
    "lines": [{
      "text": "示例文字",
      "confidence": 0.95,
      "detection_score": 0.98,
      "left": 20, "top": 30, "right": 180, "bottom": 60
    }]
  },
  "elapsed_ms": 500
}
result.width / height：解码后图片宽高（像素）。lines：按阅读顺序排列的文字行，无文字时为空数组。text：文字；confidence：识别置信度；detection_score：检测分数；left / top / right / bottom：像素坐标，左上角为原点，基于返回的图片尺寸。可选 paragraphs 为段落框，含坐标和 line_indices（对应 lines 的零基索引）。elapsed_ms：服务处理耗时（毫秒）。请求预览时额外返回 preview_png，为不含 data URL 前缀的 PNG Base64。后端不返回证件类型和模板字段，网页根据 OCR 结果自行判断。


失败响应：
{"error":{"code":"unauthorized","message":"Token 不正确或未填写"}}


HTTP 400：invalid_upload / missing_image / invalid_image / invalid_preview；401：unauthorized；413：upload_too_large；429：server_busy / rate_limited（Retry-After 为建议等待秒数）；500：recognition_failed / preview_failed / internal_error；503：service_stopping；504：recognition_timeout。404 / 405 分别表示接口不存在或方法不支持。全服务默认同时处理一个任务。
